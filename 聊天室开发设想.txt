
你是一名资深 Flutter + Dart + P2P 局域网通信 + 高性能移动端架构工程师，请为我开发一个基于 Flutter 的 VNT 组网聊天室系统（兼容 Windows / Android / IOS / Linux / macOS）。

====================
一、项目核心定位
====================

这是一个基于 VNT 虚拟组网的去中心化聊天室系统，不依赖中心聊天服务器，所有客户端通过组网后的虚拟 IP 直接通信。

每个客户端既是：
1. 聊天客户端
2. 房间节点
3. 消息同步节点
4. 文件共享节点

聊天室生命周期依赖在线成员存在，所有成员离线后聊天室自动消失。

====================
二、技术要求

可参考使用以下技术栈：

- Flutter（必须最高3.24.4版本）
- Dart （同上）
- Riverpod（状态管理）
- Isar（本地数据库）
- dart:io（Socket / ServerSocket / HttpServer）
- file_picker

- path_provider
- uuid

代码要求：

1. 高质量生产级代码结构
2. 模块化清晰
3. 所有代码完整可运行，不能省略和简化
4. 所有中文注释
5. 所有异常处理完整
6. 所有 UI 现代化，与其他页面保持一致

====================
三、聊天室发现机制
====================

组网已成功连接后在后台自动扫描当前 VNT 组网内在线聊天室列表。
进入房间页面打开聊天室TAB时：

页面显示：

1. 当前在线聊天室列表
2. 创建聊天室按钮

必须基于当前组网配置进行隔离。

例如：

组网A：
- tokenA
- 服务器地址
- 组网密码

组网B：
- tokenB
- 服务器地址
- 组网密码

要求：

只有相同组网配置的客户端，才能：

1. 发现聊天室
2. 加入聊天室
3. 查看共享文件

不同组网之间绝对隔离，不能显示彼此聊天室。

请设计安全可靠的房间广播发现机制。

推荐：

UDP 广播 / TCP 探测 / 房间心跳机制。

====================
四、创建聊天室
====================

点击创建聊天室按钮：

弹窗输入：

1. 聊天室名称
2. 房间密码（可选）

创建成功后：

当前客户端成为房主节点。

房主负责：

1. 广播房间存在
2. 成员管理
3. 消息转发（可选）
4. 历史记录同步协调

====================
五、加入聊天室
====================

加入规则：

1. 只能加入同配置的组网聊天室
2. 房间密码校验
3. 加入后立即进入聊天页面

加入成功后：

自动向任意在线客户端请求历史聊天记录。

====================
六、聊天功能
====================

支持：

1. 文字消息
2. 系统消息（谁加入、谁退出，采用设备名称（设备ip）记录）
3. 文件共享消息
4. 历史记录流式同步

文字消息要求：

1. 实时发送
2. 低延迟
3. 断线重连
4. 去重机制
5. 顺序尽量一致

建议：

TCP Socket 长连接或WS。

====================
七、聊天记录机制
====================

聊天记录由加入聊天室的客户端本地保存。

使用 Isar 数据库。

要求：

每个聊天室独立记录。

例如：

room_xxx.db

存储：

- 消息ID
- 房间ID
- 发送者，采用设备名称（设备ip）记录
- 内容
- 类型
- 时间
- 文件共享信息记录（可选）

容量限制：

每个聊天室聊天记录最大 20MB。

超过后自动循环删除最旧消息。

加入聊天室时：

自动从任意在线客户端处流式同步历史记录。

要求：

1. 分批加载
2. 不阻塞当前聊天
3. 不影响实时消息接收
4. UI 可边同步边显示

退出聊天室时：

自动删除该聊天室本地记录。

聊天室被删除时：

加入组网成功连接时自动扫描在线聊天室并对比缓存的聊天室记录，离线的自动删除本地缓存记录。

组网配置被删除时：

自动删除该组网下所有聊天室记录。

====================
八、文件共享功能
====================

聊天室内支持共享文件或文件夹。

点击共享按钮：

可选择：

1. 单个文件
2. 整个文件夹

然后启动本地高性能文件服务器。

要求：

基于 HttpServer 实现高性能下载服务。

支持：

1. 大文件下载（10GB+）
2. 多线程并发下载
3. Range 请求
4. 断点续传
5. 流式传输
6. 文件夹浏览
7. 下载速度快
8. 低内存占用

其他客户端点击共享消息后：

可查看：

1. 文件列表
2. 文件大小
3. 下载按钮

====================
九、共享悬浮提示
====================

当本机正在共享文件时：

在聊天室页面顶部显示悬浮提示条：

例如：

【正在共享文件：电影合集（点击关闭共享）】

点击后：

立即停止文件服务器并取消共享。

十、聊天室销毁机制
====================

聊天室自动销毁条件：

1. 所有成员离线

销毁后：

所有客户端自动清理：

1. 房间缓存
2. 房间消息记录
3. 房间共享状态
